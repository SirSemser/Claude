# WSKZ 2026 · IoT — материалы эксперта

Подготовка к Республиканскому чемпионату WorldSkills Kazakhstan 2026 по компетенциям
«Инженерия интеллектуальных IoT-систем» (IIoT) и «Искусственный интеллект и интернет вещей» (AI-IoT).
Набор ZL-02B (ESP32), язык — MicroPython.

**Учебник (разбор заданий, железо, MicroPython, спорные места, план на неделю, карточки):**
https://claude.ai/artifact/CExeDErc8foDHNPSBTrrS9 — та же страница лежит в `guide/index.html`.

## Что внутри

| Папка | Что это |
|---|---|
| `IIoT/A1` | Ультразвуковой дальномер + ИИ-оценка движения |
| `IIoT/A2` | Индукционная лампа (PIR + освещённость) + ИИ-подбор HOLD |
| `IIoT/B1` | Контроль загазованности (MQ-2 + WS2812) + ИИ-порог |
| `IIoT/B2` | RFID-контроль доступа (MFRC522) + ИИ-оценка риска, `users.json` |
| `IIoT/C1` | ИИ-камера: `main.py` для ESP32 и `ai_cam.py` для A01-AI (MaixPy) |
| `AI-IoT/MA` | Парктроник: итог частей A1+A2+A3 (подходит и для MA1) |
| `AI-IoT/MB` | RFID-пропуска: итог частей B1+B2+B3 |
| `tests/` | Симулятор платы на ПК и сценарии проверки всех решений |
| `guide/` | Исходники учебника и скрипт сборки |

## Важно

* Это **учебные эталоны** для подготовки. На чемпионате приносить готовый код запрещено,
  а задание изменят минимум на 30 % — студент должен уметь написать всё сам.
* Имена методов драйверов `HCSR04.py` и `rc522.py` взяты из текста задания или предположены.
  Места, которые нужно сверить с драйверами на площадке, помечены в коде словом `СВЕРИТЬ`.
* На реальной плате код ещё не запускался. Логика проверена в симуляторе (`tests/`).
* `secrets.py` (Wi-Fi и API-ключ) хранится только на плате и исключён через `.gitignore`.

## Проверка в симуляторе

```bash
python3 tests/run_all.py
```

Симулятор подменяет `machine`, `network`, `ssd1306`, `neopixel`, драйверы датчиков, `requests`
и время на заглушки, прогоняет каждый `main.py` по сценарию (датчики, ответы ИИ, карты, строки UART)
и сверяет экраны и журнал с требованиями заданий.

## Пересборка учебника

```bash
python3 guide/build.py            # -> guide/index.html
```
