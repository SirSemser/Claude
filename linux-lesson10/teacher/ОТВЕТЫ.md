## case

### F1. Калькулятор на case — 6 б.

Аргументы: число, операция, число. Операции: `+ - x / %` (умножение — буква `x`, потому что `*` оболочка превращает в список файлов).
```
$ ./calc.sh 12 x 5
12 x 5 = 60
$ ./calc.sh 7 / 0
Ошибка: деление на ноль
$ ./calc.sh 2 ^ 3
Неизвестная операция: ^
```
При делении (/ или %) на ноль завершайте скрипт с кодом 2, при неизвестной операции — с кодом 1.

**Эталонное решение:**

```bash
#!/bin/bash
# F1. Калькулятор на case
a=$1
op=$2
b=$3
case $op in
    +) echo "$a + $b = $((a + b))" ;;
    -) echo "$a - $b = $((a - b))" ;;
    x) echo "$a x $b = $((a * b))" ;;
    /|%)
        if [ "$b" -eq 0 ]; then
            echo "Ошибка: деление на ноль"
            exit 2
        fi
        if [ "$op" = "/" ]; then
            echo "$a / $b = $((a / b))"
        else
            echo "$a % $b = $((a % b))"
        fi
        ;;
    *)
        echo "Неизвестная операция: $op"
        exit 1
        ;;
esac
```

**Тесты (8):** `12 + 5`, `12 - 5`, `12 x 5`, `12 / 5`, `12 % 5`, `7 / 0`, `9 % 0`, `2 ^ 3`

**Требования к коду:** используйте case.

## Функции

### G1. Простые числа (функция) — 6 б.

Напишите функцию `is_prime`, которая возвращает код 0, если её аргумент — простое число, и 1 — если нет. С её помощью выведите в одну строку все простые числа от 2 до N:
```
$ ./primes.sh 20
Простые числа до 20: 2 3 5 7 11 13 17 19
$ ./primes.sh 1
Нет простых чисел
```

**Эталонное решение:**

```bash
#!/bin/bash
# G1. Простые числа с функцией
is_prime() {
    local n=$1
    if [ $n -lt 2 ]; then
        return 1
    fi
    for (( d=2; d*d<=n; d++ )); do
        if [ $((n % d)) -eq 0 ]; then
            return 1
        fi
    done
    return 0
}
limit=$1
result=""
for (( i=2; i<=limit; i++ )); do
    if is_prime $i; then
        result+="$i "
    fi
done
if [ -z "$result" ]; then
    echo "Нет простых чисел"
else
    echo "Простые числа до $limit: $result"
fi
```

**Тесты (4):** `20`, `2`, `1`, `50`

**Требования к коду:** объявите функцию: is_prime() { ... }; функция должна возвращать результат через return.

## Итоговые

### I1. Банковский счёт (бонус) — 6 б.

Скрипт читает команды со стандартного ввода (по одной в строке) циклом `while read` и обрабатывает их через `case` и функции. Начальный баланс — 0.
- deposit N → Пополнение: N. Баланс: B
- withdraw N → Снятие: N. Баланс: B — или, если денег мало: Недостаточно средств. Баланс: B
- balance → Баланс: B
- exit → До свидания! (и выход из цикла)
- другое → Неизвестная команда: X
```
$ ./bank.sh
deposit 100
Пополнение: 100. Баланс: 100
withdraw 30
Снятие: 30. Баланс: 70
exit
До свидания!
```

**Эталонное решение:**

```bash
#!/bin/bash
# I1. Банковский счёт
balance=0
deposit() {
    balance=$((balance + $1))
    echo "Пополнение: $1. Баланс: $balance"
}
withdraw() {
    if [ $1 -gt $balance ]; then
        echo "Недостаточно средств. Баланс: $balance"
    else
        balance=$((balance - $1))
        echo "Снятие: $1. Баланс: $balance"
    fi
}
while read -r cmd amount; do
    case $cmd in
        deposit) deposit "$amount" ;;
        withdraw) withdraw "$amount" ;;
        balance) echo "Баланс: $balance" ;;
        exit) echo "До свидания!"; break ;;
        *) echo "Неизвестная команда: $cmd" ;;
    esac
done
```

**Тесты (3):** ` ← "deposit 100\nwithdraw 30\nbalance\nexit\n"`, ` ← "withdraw 10\ndeposit 50\nfoo\nwithdraw 60\ndeposit 25\nbalance\nexit\nbalance\n"`, ` ← "deposit 5\nbalance\n"`

**Требования к коду:** оформите операции функциями; используйте case; используйте цикл while read.

Аргумент — пароль. Проверьте 5 условий и выведите «да»/«нет» для каждого и итог:

#!/bin/bash
# I2. Проверка пароля
p=$1
score=0
check() {
    if [ $2 -eq 1 ]; then
        echo "$1: да"
        score=$((score + 1))
    else
        echo "$1: нет"
    fi
}
[ ${#p} -ge 8 ] && r=1 || r=0;      check "Длина >= 8" $r
[[ $p =~ [0-9] ]] && r=1 || r=0;     check "Есть цифра" $r
