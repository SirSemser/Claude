Практика

Отладка и хорошие привычки

bash -x script.sh

Печатает каждую команду с уже подставленными значениями. Внутри скрипта: set -x … set +x.

bash -n script.sh

Только проверка синтаксиса, без выполнения.

set -euo pipefail

Остановиться при ошибке команды, при пустой переменной и при сбое в конвейере.

shellcheck.net

Онлайн-проверка скрипта: находит типичные ошибки и объясняет их. Устанавливать ничего не нужно.

Привычки: "$переменные" в кавычках · понятные имена · комментарии «зачем» · exit 0 при успехе и exit 1 при ошибке.

bash -x — главный инструмент отладки: видно, какие значения подставились и по какой ветке пошёл скрипт. Покажите его на скрипте с ошибкой в условии. В учебном терминале лабораторной bash -x тоже работает. ShellCheck — бесплатный анализатор, на сайте shellcheck.net достаточно вставить текст скрипта.
