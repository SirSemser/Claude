Shell — оболочка

Принимает команды пользователя и передаёт их ядру. Бывает CLI (bash в терминале) и GUI (графический рабочий стол).

Kernel — ядро

Сердце системы: управляет процессами, памятью, файлами и устройствами.

Hardware — аппаратура

Процессор, память, диски, сеть.

Bash — The Bourne-Again Shell, самая распространённая оболочка Linux.

Пользователь не обращается к ядру напрямую — между ними оболочка. Она читает команду, находит программу и просит ядро её запустить. Оболочка бывает текстовой (CLI) и графической (GUI). Сегодня работаем с текстовой — bash.
