Операции со строками

ЗаписьРезультатЧто делает
${#s}15длина
${s:0:6}reportподстрока
${s: -3}txtс конца
${s%.*}report_2026убрать хвост
${s##*.}txtубрать начало
${s/2026/2027}report_2027.txtзаменить
${s//r/R}RepoRt_2026.txtзаменить все
${s^^}REPORT_2026.TXTзаглавные

s="report_2026.txt"

% отрезает с конца, # — с начала. Одинарный знак — кратчайшее совпадение, двойной — самое длинное.

,, — строчные, ^ — первая заглавная.

Склейка: full="$first $last"

Это встроенные операции bash — они работают без внешних программ и поэтому быстрые. Запомнить % и # помогает клавиатура: # стоит слева от $, значит режет слева, % — справа, режет справа. В ${s: -3} пробел перед минусом обязателен, иначе получится другая конструкция. Задание D1 целиком на этот слайд.
