Permission denied

Нет права x → chmod +x script.sh

command not found

Забыли ./ перед именем файла

required file not found

Ошибка в shebang, например #!bin/bash

Покажите разницу между ./script.sh и source script.sh на примере скрипта с cd /tmp: после ./ мы остаёмся в той же папке, после source — оказываемся в /tmp. Три карточки внизу — самые частые сообщения об ошибках у новичков. В bash 5.2 при неверном shebang сообщение звучит как cannot execute: required file not found, в старых версиях — bad interpreter.
