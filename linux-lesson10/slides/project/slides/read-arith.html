Variable

Ввод с клавиатуры и арифметика

read -p "Введите имя: " name
read -r a b           # два слова → две переменные
echo $(( a + b ))  $(( a * b ))
echo $(( 17 / 5 ))      # 3 — деление целое
echo $(( 17 % 5 ))      # 2 — остаток
echo $(( 2 ** 10 ))     # 1024 — степень
(( count++ ))          # увеличить на 1
let total=a+b
echo "scale=2; 10/3" | bc # 3.33

read ждёт строку со стандартного ввода и раскладывает слова по переменным.

Внутри $(( )) переменные пишут без $, пробелы можно ставить свободно.

Bash считает только целые числа. Для дробей — команда bc.

read -p выводит подсказку, -r отключает обработку обратной косой черты — так безопаснее. Деление в bash всегда целочисленное: 17/5 даёт 3. Остаток от деления (%) пригодится для проверки чётности. Старые формы expr и $[ ] тоже встречаются в учебниках, но современный вариант — $(( )).
