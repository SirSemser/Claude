Condition

Операторы сравнения

Числа

-eq  равно
-ne  не равно
-lt  меньше
-le  меньше или равно
-gt  больше
-ge  больше или равно

Строки

=    равны
!=   не равны
-z   пустая
-n   не пустая
\< \> по алфавиту

Файлы

-e  существует
-f  обычный файл
-d  каталог
-r -w -x права
-s  не пустой

[ -f data.txt ] && [ "$n" -gt 0 ]   # И
[ ! -d backup ] || echo "есть"      # НЕ, ИЛИ

Частая путаница: для чисел используют буквенные операторы (-eq, -lt), а = и != — для строк. Знаки < и > внутри [ ] нужно экранировать, иначе bash примет их за перенаправление. Логические связки: && (и), || (или), ! (не). Внутри одной пары [ ] старые варианты -a и -o тоже работают.
