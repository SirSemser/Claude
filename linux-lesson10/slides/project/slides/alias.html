Alias

Alias — короткое имя для команды

$ alias                # список всех
$ alias c='clear'      # создать
$ alias ll='ls -l'
$ alias ping='ping -c4'
$ alias sshconfig='sudo vim /etc/ssh/sshd_config'
$ unalias c            # удалить
$ type ll
ll is aliased to `ls -l'

Чтобы алиас сохранился

$ echo "alias ll='ls -l'" >> ~/.bashrc
$ source ~/.bashrc

  • без ~/.bashrc алиас пропадёт после закрытия терминала
  • вокруг = не ставим пробелы
  • \ls — запустить команду в обход алиаса
  • в скриптах алиасы не работают — там пишут функции
Alias — «лақап ат», псевдоним. Удобен для длинных команд, которые набираем часто. Важно: alias действует только в текущем терминале. Чтобы он был всегда, дописываем строку в ~/.bashrc и перечитываем файл командой source. В лабораторной это задания T2 и T3.
