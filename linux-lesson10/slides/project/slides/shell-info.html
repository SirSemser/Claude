Оболочка

Как узнать свою оболочку

$ echo $SHELL       # оболочка входа
/bin/bash
$ echo $0           # что работает сейчас
bash
$ cat /etc/shells   # разрешённые оболочки
$ cat /etc/passwd | grep student
$ getent passwd student
student:x:1000:1000::/home/student:/bin/bash
$ chsh -s /bin/zsh  # сменить оболочку

$SHELL

Оболочка по умолчанию — последнее поле строки пользователя в /etc/passwd.

$0

Имя программы, которая выполняется сейчас. Внутри скрипта — имя самого скрипта.

$SHELL показывает, какая оболочка назначена пользователю при входе, а $0 — что реально работает сейчас. Если запустить zsh из bash, $SHELL останется /bin/bash, а $0 станет zsh. В оболочке входа $0 иногда выглядит как -bash: минус означает login shell. В лабораторной задание T1 повторяет эти команды.
