Function

Функции

greet() {
    local name=$1      # видна только внутри
    echo "Привет, $name!"
}
is_even() {
    (( $1 % 2 == 0 ))  # код 0 — «да»
}

greet "Дана"            # Привет, Дана!
if is_even 10; then echo "чётное"; fi
msg=$(greet "Тимур")   # вывод → переменная

Аргументы функции — тоже $1, $2, $#, $@.

return N возвращает код 0–255, а не значение. Значение отдают через echo и забирают через $( ).

local защищает переменные скрипта от случайной перезаписи.

Функцию объявляют выше места вызова.

Функция — именованный кусок кода, который можно вызывать много раз. Главное отличие от других языков: return передаёт только код завершения (успех или ошибка), поэтому функцию-проверку удобно ставить прямо в if. Если нужно вернуть число или строку — печатаем echo и забираем через $( ). Задание G1 — функция is_prime.
