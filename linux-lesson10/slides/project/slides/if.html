Condition

Условие if

#!/bin/bash
score=$1
if [ "$score" -ge 90 ]; then
    echo "Отлично"
elif [ "$score" -ge 50 ]; then
    echo "Сдал"
else
    echo "Не сдал"
    exit 1
fi

1

Внутри [ ] пробелы обязательны: [ "$a" -gt 5 ]

2

[ — это команда test. Условие истинно, если команда вернула код 0.

3

Переменные в кавычках: пустая $a без кавычек даёт ошибку unary operator expected.

4

Каждый if закрывается fi, elif и else — по желанию.

if проверяет код завершения команды: 0 — истина. Поэтому после if можно ставить любую команду, например if grep -q root /etc/passwd. Квадратная скобка — это обычная команда, отсюда обязательные пробелы. exit 1 завершает скрипт с кодом ошибки — это пригодится в заданиях C1 и F1.
