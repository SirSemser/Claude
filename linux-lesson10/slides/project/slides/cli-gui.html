Оболочка

Два интерфейса: CLI и GUI

CLI · командная строка

bash, zsh, sh, fish

  • команды вводятся текстом
  • работает на серверах без графики и по SSH
  • действия можно записать в скрипт и повторять

GUI · графический рабочий стол

GNOME, KDE Plasma, Xfce

  • ещё: Cinnamon, MATE, LXQt (наследник LXDE)
  • графика: X11 (X Window System) и Wayland — новый стандарт, по умолчанию в Ubuntu, Fedora, RHEL 10
  • Display Manager — экран входа, Window Manager — управление окнами
Графический рабочий стол — тоже оболочка, только с окнами и мышью. На серверах графики обычно нет, поэтому администратор работает в CLI. Обновление по сравнению с прошлым годом: Wayland постепенно заменяет X11 — в RHEL 10 сервер Xorg уже убран, графические сессии идут через Wayland. LXDE больше не развивается, его продолжение — LXQt.
