Case

Выбор по шаблону: case

read -p "Продолжить? (y/n) " answer

case "$answer" in
    y|Y|yes) echo "Продолжаем" ;;
    n|N|no)  echo "Отмена" ;;
    [0-9]*)  echo "Это число" ;;
    *)       echo "Не понял ответ" ;;
esac

Шаблоны — как у имён файлов: * любые символы, ? один символ, [abc] один из списка, | — «или».

;; завершает ветку, *) — «всё остальное».

Удобно для меню и команд вида start | stop | restart.

case заменяет длинную цепочку if/elif, когда одну переменную сравнивают с несколькими вариантами. Срабатывает первая подходящая ветка. Задания F1 (калькулятор) и F2 (тип файла по расширению). Подсказка для F2: перед case приведите расширение к нижнему регистру — ${ext,,}.
