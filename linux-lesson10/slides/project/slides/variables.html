Variable

Переменные

name="Aigerim"         # без пробелов у =
age=19
echo "Привет, $name!" # Привет, Aigerim!
echo "Через год: $((age + 1))"
echo "${name}_backup"  # скобки отделяют имя
echo '$name'          # выведет $name
today=$(date +%d.%m.%Y)# вывод команды
readonly PI=3.14       # константа
unset name             # удалить

Частые ошибки

name = "Ali"

→ name: command not found

echo $text

без кавычек лишние пробелы схлопнутся — пишите "$text"

Имя: буквы, цифры и _, не с цифры. NAME и name — разные переменные.

Главное правило: при присваивании нет пробелов вокруг знака равно, иначе bash примет имя за команду. Двойные кавычки подставляют значения переменных, одинарные — нет. Конструкция $( ) подставляет вывод команды. Фигурные скобки нужны, когда сразу после имени идут буквы или цифры.
