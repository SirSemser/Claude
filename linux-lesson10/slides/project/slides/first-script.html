Первый скрипт за 4 шага

$ which -a bash
/usr/bin/bash
/bin/bash
$ nano script1.sh
#!/bin/bash
echo 'Hello World!'
$ chmod +x script1.sh  # или 755
$ ./script1.sh
Hello World!

#

Sharp

!

Bang

#!

Shebang

Shebang — первая строка: путь к интерпретатору, который выполнит файл. Переносимый вариант: #!/usr/bin/env bash

chmod +x даёт право на выполнение, ./ говорит «файл в текущей папке».

Четыре шага: 1) находим путь к bash (which -a bash); 2) создаём файл в nano, первая строка — shebang; 3) даём право на выполнение chmod +x (или 755 — rwxr-xr-x); 4) запускаем ./script1.sh. Без ./ bash будет искать команду в PATH и не найдёт её. В лабораторной это задание T4.
