Скрипт с комментариями

#!/bin/bash
mkdir -p dir1
# This is a Bash comment
echo 'Welcome to Almaty!' > dir1/file1.txt
ls -l dir1         # listing the directory
cat dir1/file1.txt # file contents

$ chmod +x script2.sh
$ ./script2.sh

Комментарий начинается с # и продолжается до конца строки — bash его пропускает.

Shebang тоже начинается с #, но это инструкция для системы, а не комментарий.

Несколько строк сразу:

: '
Это блок,
который bash не выполнит
'

Пример со слайда исходной презентации. Комментарии объясняют, зачем нужна команда, а не пересказывают её. Многострочный «комментарий» через : '...' — это на самом деле пустая команда : со строкой-аргументом; работает, пока внутри нет одинарных кавычек. В лабораторной это задание T5.
