Скрипт, написанный по стандарту POSIX, работает в любой оболочке семейства Bourne.

Две большие ветки: Bourne (sh, bash, dash, ksh, zsh) и C shell (csh, tcsh). Bash — расширенный Bourne shell, поэтому почти все скрипты для sh работают и в bash, но не наоборот. В Ubuntu /bin/sh — это dash, поэтому скрипт с bash-синтаксисом нужно запускать именно через bash (shebang #!/bin/bash).
