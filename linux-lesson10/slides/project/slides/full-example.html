Всё вместе: отчёт по группе

#!/bin/bash
file=${1:-students.txt}
[ -f "$file" ] || { echo "Нет файла $file"; exit 1; }
grade() {
    local s=$1
    if (( s >= 90 )); then echo "A"
    elif (( s >= 75 )); then echo "B"
    elif (( s >= 50 )); then echo "C"
    else echo "F"; fi
}
declare -A count
while read -r last first score; do
    g=$(grade "$score")
    count[$g]=$(( ${count[$g]:-0} + 1 ))
    echo "$last $first $score $g"
done < "$file"
for g in A B C F; do
    echo "$g: ${count[$g]:-0}"
done

Здесь есть всё: значение по умолчанию ${1:-…}, проверка файла, функция с local, while read, ассоциативный массив и for.

Итоговый пример собирает темы урока в один полезный скрипт. Разберите его сверху вниз: аргумент со значением по умолчанию, проверка существования файла с выходом exit 1, функция grade с local, чтение файла циклом while read, подсчёт оценок в ассоциативном массиве и вывод итогов циклом for. Файл students.txt лежит в папке ~/lab10 учебного терминала — пример можно запустить прямо там.
