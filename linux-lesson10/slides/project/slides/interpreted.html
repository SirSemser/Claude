Интерпретатор bash читает и выполняет команду за командой

Java — смешанный путь: компилятор → байт-код → виртуальная машина JVM.

Bash не проверяет скрипт целиком заранее: команды до ошибки успеют выполниться.

Скрипт bash не компилируется, его построчно читает интерпретатор. Отсюда практический вывод: синтаксическая ошибка в середине скрипта проявится только тогда, когда bash до неё дойдёт, а команды выше уже выполнятся. Поэтому перед запуском «опасных» скриптов полезно проверить синтаксис: bash -n script.sh.
