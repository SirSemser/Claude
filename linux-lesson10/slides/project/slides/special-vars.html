Variable

Аргументы и специальные переменные

ПеременнаяЗначение
$0имя скрипта
$1 … $9, ${10}аргументы по номеру
$#количество аргументов
$@все аргументы по отдельности
$?код последней команды (0 — успех)
$$номер процесса (PID)
$RANDOMслучайное число 0–32767
$HOME $USER $PWDпеременные окружения

#!/bin/bash   # args.sh
echo "Скрипт: $0"
echo "Аргументов: $#"
echo "Все: $@"
echo "Первый: $1"

$ ./args.sh a b c
Скрипт: ./args.sh
Аргументов: 3
Все: a b c
Первый: a

Аргументы — это слова после имени скрипта. Они превращают скрипт в инструмент: один и тот же код работает с разными данными. $? проверяют сразу после команды: 0 означает успех, любое другое число — ошибку. Внутри функции $1, $2 и $# относятся уже к аргументам функции.
