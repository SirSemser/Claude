Array

Массивы

Обычный (индексы 0, 1, 2…)

colors=(red green blue)
echo ${colors[0]}     # red
echo ${colors[@]}     # все
echo ${#colors[@]}    # 3
colors+=(white)       # добавить
echo ${!colors[@]}    # 0 1 2 3
for c in "${colors[@]}"; do
    echo $c
done

Ассоциативный (ключ → значение)

declare -A age
age[ali]=20
age[dana]=19
echo ${age[dana]}     # 19
echo ${!age[@]}       # ключи
echo ${#age[@]}       # 2

Порядок ключей не гарантирован — для вывода используйте sort.

Массив хранит много значений под одним именем. Обычный массив нумеруется с нуля; "${arr[@]}" в кавычках — правильный способ перебрать элементы, даже если в них есть пробелы. Аргументы скрипта легко сохранить в массив: nums=("$@"). Ассоциативный массив (bash 4+) объявляется обязательно через declare -A. Задания H1–H3.
