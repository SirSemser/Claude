Condition

[[ ]], (( )) и короткие условия

[[ $name == A* ]] && echo "Имя на A"              # шаблон
[[ $email =~ ^[a-z]+@[a-z]+\.kz$ ]] && echo OK # регулярное выражение
[[ $age -ge 18 && $age -le 25 ]]             # && внутри скобок
(( age >= 18 )) && echo "взрослый"          # арифметика
mkdir backup && cd backup                    # если успешно
cd /nope || echo "нет такой папки"        # если ошибка

[ ]

Классика POSIX, работает в любой оболочке.

[[ ]]

Только bash: шаблоны, =~, && и || внутри, меньше проблем с кавычками.

(( ))

Сравнение чисел привычными знаками < > == и без $.

Двойные квадратные скобки — расширение bash: внутри можно сравнивать с шаблоном (A*), с регулярным выражением (=~) и использовать && и ||. Двойные круглые скобки — для чисел. Цепочки команда1 && команда2 и команда1 || команда2 — короткая запись if для одной команды. В задании I2 регулярные выражения проверяют надёжность пароля.
