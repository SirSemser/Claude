Loop

Циклы while и until

n=1
while [ $n -le 3 ]; do
    echo "Шаг $n"
    n=$((n + 1))   # без этого — бесконечно
done

until [ $n -eq 0 ]; do ((n--)); done

# чтение файла построчно
while read -r name score; do
    echo "$name: $score"
done < students.txt

while

повторяет, пока условие истинно

until

повторяет, пока условие ложно

break · continue

выйти из цикла · перейти к следующему шагу

Самая частая ошибка — забыть изменить счётчик: цикл становится бесконечным, выход — Ctrl+C. В лабораторной симулятор сам остановит скрипт через 4 секунды. Конструкция while read ... done < файл — стандартный способ обработать файл построчно; read раскладывает слова строки по переменным. Задания E2 и E3.
