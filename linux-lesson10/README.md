# Linux · Урок 10. Bash Shell Scripting

Материалы урока на русском языке: обновлённая презентация и лабораторная работа, которая работает
в браузере без установки программ.

## Что раздавать студентам

**`dist/lab10_bash.html`** — один файл. Его можно отправить по почте, в Telegram или выложить в Classroom.
Студент открывает файл в Chrome, Edge или Firefox (интернет не нужен) и получает:

* учебный терминал Linux (bash 5.2) с файлами в `~/lab10`, редактором `nano`, историей команд и подсказками на русском;
* редактор скриптов с подсветкой, кнопками «Запустить» и «Проверить»;
* 33 задания на ~60 минут: 6 вопросов-разминок, 5 заданий в терминале, 22 скрипта
  (основные — 100 баллов, бонусные — +46);
* автосохранение в браузере и кнопку **«Скачать результат»** — файл `Lab10_Familiya_Imya_Gruppa.html`,
  который студент отправляет преподавателю.

## Как проверить работы

Откройте `lab10_bash.html`, на стартовом экране нажмите **«Режим преподавателя»** (или добавьте к адресу `#teacher`)
и перетащите присланные файлы. Каждое решение заново запускается на всех тестах; получится таблица
с баллами, деталями по каждому студенту, историей команд и выгрузкой в Excel (CSV).

Ключ ответов с эталонными решениями — `teacher/ОТВЕТЫ.md` (студентам не раздавать).

## Устройство лабораторной

| Путь | Что это |
|---|---|
| `lab/src/vfs.js`, `parser.js`, `arith.js`, `shell.js`, `commands.js`, `awk.js` | Интерпретатор bash на JavaScript и виртуальная файловая система |
| `lab/src/tasks.js` | Тексты заданий, тесты, проверки терминальных заданий |
| `lab/src/labcore.js`, `app.js`, `style.css`, `template.html` | Проверка заданий и интерфейс |
| `lab/solutions/` | Эталонные решения (в HTML не попадают) |
| `lab/build.js` | Сборка: считает ожидаемые ответы **настоящим bash**, сверяет с симулятором, собирает `dist/lab10_bash.html` |
| `lab/test/` | Сравнение симулятора с bash: корпус скриптов и альтернативные «студенческие» решения |
| `lab/make_answers.js` | Генерирует `teacher/ОТВЕТЫ.md` |

```bash
cd linux-lesson10/lab
node build.js                 # проверка эталонов + сборка dist/lab10_bash.html
node test/conformance.js      # симулятор против bash на корпусе скриптов
node test/alt_solutions.js    # альтернативные решения студентов
node make_answers.js          # ключ ответов
```

Ограничения симулятора: это учебная модель bash, а не настоящий Linux. Нет сети, установки пакетов,
`sudo`, фоновых процессов и символических ссылок; `awk`, `sed` и `bc` упрощены. Всё, что нужно для заданий,
проверено на совпадение с настоящим bash 5.2.
